## 当前规则

- 每条字幕中文最多 **100 个可见字符**：去空白后计数，标点和公式计入。
- 先保证完整句义、定义、证明步骤和问答对应，再在自然分句点切分。
- 不按秒数、英文词数或板书停顿切分；不重译、不丢句、不改数学文字。
- 视频和最终双语字幕放在 `videos/`，文件名统一为 `abstract-algebra-NN.*`。

### [P06] 第 06 讲：模算术与商群引论 (Quotient Groups & Congruence)
- **视频简介**：本讲从我们自幼熟悉的“奇数与偶数算术”切入，极其自然地推广到模 $n$ 整数剩余类加法群 $\mathbb{Z}/n\mathbb{Z}$。Gross 教授通过同余关系剖析了陪集（Coset）的划分机制，为整个抽象代数最关键的“商群”概念打下了坚实的直觉基础。
- **教材章节**：Artin *Algebra* §2.9 – §2.10
- **核心关键词**：模算术 / 奇偶算术 / 同余关系 / 陪集 / 整数剩余类群 / 商群直觉

- **视频简介**：本讲正式建立商群的严格公理化定义：为什么只有当子群是“正规子群”时，陪集之间的乘法才能良定义？教授详细考察了整数加法群的所有子群形态（$n\mathbb{Z}$），并澄清了正规子群判定条件的核心必要性。
- **教材章节**：Artin *Algebra* §2.10, §3.1 – §3.2
- **核心关键词**：正规子群 / 循环群 / 陪集乘法良定义 / 整数子群 / 商群构造

### [P08] 第 08 讲：群的第一同构定理 (First Isomorphism Theorem)
- **视频简介**：本讲深入讲授代数学基石定理——群的第一同构定理：任何群同态的像同构于定义域模去同态核（$G/\ker f \cong \text{im } f$）。同时讲授了子群对应定理（格同构），展示了商群如何完美反映原群的中间子群结构。
- **教材章节**：Artin *Algebra* §3.1 – §3.2
- **核心关键词**：第一同构定理 / 同态核 / 对应定理 / 格同构 / 满同态

- **视频简介**：从本讲起课程暂时跳出群论，拓展到一般域上的线性代数。Gross 教授给出了抽象域的严格公理定义，介绍了有限域与域的特征，并构建了一般域上抽象向量空间与线性无关性的完整框架。
- **教材章节**：Artin *Algebra* §3.3 – §3.4
- **核心关键词**：抽象域 / 有限域 / 域特征 / 向量空间公理 / 线性无关

### [P10] 第 10 讲：基的扩充与维数定理 (Bases & Dimension Theorems)
- **视频简介**：本讲探讨有限维向量空间的核心骨架：证明任意线性无关向量组均可扩充为一组基，证明有限维基向量个数的唯一性（维数），并讲授子空间直和与商空间的维数公式。
- **教材章节**：Artin *Algebra* §3.4, §4.1 – §4.2
- **核心关键词**：基的扩充定理 / 维数唯一定理 / 有限维向量空间 / 基变换

### [P11] 第 11 讲：线性算子与矩阵表示 (Linear Operators & Matrix Representations)
- **视频简介**：本讲剖析线性算子的矩阵代数本质：如何将抽象线性变换在选定基下表示为矩阵？坐标变换公式如何导出矩阵相似性？教授结合一般线性群 $\text{GL}_n(F)$ 深入揭示了算子代数背后的对称群结构。
- **教材章节**：Artin *Algebra* §4.1 – §4.4
- **核心关键词**：线性算子 / 矩阵表示 / 相似变换 / 一般线性群 / 坐标变换

### [P12] 第 12 讲：第一次期中考试总复习 (Midterm 1 Review)

### [P14] 第 14 讲：正交群与欧几里得结构 (The Orthogonal Group)
- **视频简介**：在一般向量空间中引入双线性内积结构，定义保持内积不变的自同构群——正交群 $\text{O}_n$。探讨保距变换的几何意义与行列式为 $+1$ 的特殊正交群 $\text{SO}_n$ 的旋转本质。
- **教材章节**：Artin *Algebra* §5.1 – §5.3
- **核心关键词**：正交群 / 内积空间 / 保距变换 / 特殊正交群 / 旋转矩阵

### [P15] 第 15 讲：平面刚体运动群 (Isometries of the Plane)
- **视频简介**：研究二维欧几里得平面的全部等距同构（刚体运动）：平移、旋转、反射与滑动反射。Gross 教授通过代数方法揭示了平移群作为正规子群的特殊地位，以及运动群作为半直积的精妙构造。
- **教材章节**：Artin *Algebra* §5.3 – §5.4
- **核心关键词**：刚体运动群 / 等距同构 / 平移正规子群 / 半直积 / 反射与滑动反射

### [P16] 第 16 讲：离散运动群与不动点定理 (Discrete Groups & Fixed Point Theorem)
- **视频简介**：聚焦平面刚体运动群的有限子群与离散子群。证明了核心的不动点定理：刚体运动群的任意有限子群在空间中必存在公共不动点，因此本质上等价于固定原点的正交群有限子群。
- **教材章节**：Artin *Algebra* §5.4 – §5.5
- **核心关键词**：不动点定理 / 离散子群 / 刚体运动分类 / 旋转对称中心

### [P17] 第 17 讲：晶体学限制与平面密铺 (Crystallographic Restriction & Wallpaper Groups)
- **视频简介**：为什么自然界晶体和平面二维密铺的旋转对称阶数只能是 1、2、3、4、6，而绝不可能出现 5 重旋转对称？本讲从点阵代数特征值出发证明著名的晶体学限制定理，并概述平面 17 种壁纸群的代数归类。
- **教材章节**：Artin *Algebra* §5.5 – §5.7
- **核心关键词**：晶体学限制定理 / 壁纸群 / 平面密铺 / 二维格子 / 点群

### [P18] 第 18 讲：群作用与轨道-稳定子群定理 (Group Actions & Orbit-Stabilizer)
- **视频简介**：正式引入近世代数的最强工具——“群作用”。详细剖析群作用公理、轨道（Orbit）、稳定子群（Stabilizer），并证明极其优美的轨道-稳定子群定理（$|G| = |O(s)| \cdot |G_s|$）与共轭子群性质。
- **教材章节**：Artin *Algebra* §5.7, §6.1 – §6.2
- **核心关键词**：群作用 / 轨道 / 稳定子群 / 轨道-稳定子群定理 / 共轭作用
