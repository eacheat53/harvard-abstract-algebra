# Subtitle QA archive

## Keep

- `current/` — current verified record. `before/` is a project-layout mirror before the last write; `after/` is the verified output; `manifest.json` contains hashes, timing QA and fallback notes.
- `history/semantic-verified-2026-10-13.tar.gz` — historical pre-reorganization audit baseline.
- `history/reorg-20261013.json` — file-by-file migration ledger with hashes and duplicate-removal verification.
- `previews/abstract-algebra-36.max100.png` — rendered preview of the current 100-character rule.
- `legacy/run_global_rebalance.py` — archived old implementation, not used by `tools/run_global_rebalance.py`.

## Safe to delete

`cache/`, `stage-*`, `*-reorg/` and `*.log` are regenerated by the batch runner. They are ignored by `.gitignore`.

Do not delete `current/before/` unless a newer verified backup exists.
